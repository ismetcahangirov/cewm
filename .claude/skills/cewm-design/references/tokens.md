# Tokens: colour, logo, spacing, radius, shadow

The paste-ready Tailwind v4 block is `tokens.css`. It goes into `app/globals.css` directly after
`@import "tailwindcss";`. It resets Tailwind's default colours, type scale, weights, radii,
shadows, blurs and easings (`--*-*: initial`), so a class outside this system (`text-blue-500`,
`text-xl`, `rounded-lg`, `shadow-md`, `font-bold`, `bg-black`, `ease-out`) generates no CSS at all
and the mistake shows in the first screenshot.

Verified on 2026-11-19 with Tailwind CSS 4.3.5 (`@tailwindcss/cli`): every utility named in this
skill compiles to exactly one rule (`text-display`, `text-h1`, `text-label`, `bg-navy`,
`text-cyan-ink`, `border-line-strong`, `py-section`, `px-gutter`, `gap-column`, `h-header`,
`rounded-xs`, `rounded-md`, `rounded-full`, `shadow-island`, `backdrop-blur-glass`,
`ease-out-expo`, `duration-400`, `container-page`, `surface-navy`, `tabular`, `font-display`,
`animate-rise`, `bg-white/10`, `bg-navy/90`), the reset defaults above produce nothing, and
`.inline-block` has a single `display` rule (no spacing token collides with a utility name).

(`from-navy-deep/70 to-transparent`, `from-navy-deep/60 to-transparent`).

### Where cyan may be used

- On `navy`, `navy-deep`, `navy-raised`: text of any size, icons, the active nav item, the
  progress rail, the focus ring, 2 px rules. Measured 7.72, 8.53 and 6.52:1.
- As a fill (button, chip, selection highlight) only with `ink` text on it (7.72:1).
- On `white` and `mist`: never as text or as a meaningful icon (2.24 and 2.07:1 fail even the
  3:1 non-text rule). Allowed only as decoration next to a text label that already carries the
  meaning (a 2 px rule under an eyebrow, a bullet square). Use `cyan-ink` for text there.

### Focus and selection

`--color-focus` is `navy` on light surfaces and switches to `cyan` inside `.surface-navy`
(the `surface-navy` utility sets it). Ring: `outline: 2px solid var(--color-focus);
outline-offset: 2px` on `:focus-visible`, never removed. Selection: `cyan` background with
`navy` text (7.72:1).

### States

| State | Light surface | Navy surface |
|---|---|---|
| Hover (button) | `navy` to `navy-raised` | `cyan` to `white` fill, `ink` label |
| Active / pressed | `translateY(1px)` | same |
| Selected (chip, tab) | `bg-cyan-ink text-white` | `bg-cyan text-ink` |
| Disabled | `opacity-40`, `cursor-not-allowed`, no hover | same |
| Error | `text-danger`, control border `danger` | forms are not placed on navy |
| Current page (nav) | `text-ink` with a 2 px `cyan-ink` underline | `text-cyan` |

## Spacing

Tailwind's 0.25 rem scale (`--spacing: 0.25rem`, unchanged) plus four fluid tokens:

| Token | Value | Range | Use |
|---|---|---|---|
| `--spacing-section` | `clamp(4rem, 2.6154rem + 6.1538vw, 10rem)` | 64 px at 360 to 160 px at 1920 | `py-section`, `mt-section`: between sections and inside bands |
| `--spacing-gutter` | `clamp(1.25rem, 0.8462rem + 1.7949vw, 3rem)` | 20 to 48 px | `container-page` side padding, `px-gutter` |
| `--spacing-column` | `clamp(1rem, 0.6667rem + 1.4815vw, 2rem)` | 16 px at 360 to 32 px at 1440 | `gap-column`: grid column gap |
| `--spacing-header` | `clamp(4rem, 3.75rem + 1.1111vw, 4.75rem)` | 64 to 76 px | `h-header`, `scroll-mt-header` |

Names are checked against utility names: never call a spacing token `block`, `flex`, `grid`,
`table`, `full`, `screen` or `auto` (`--spacing-block` turns `inline-block` into a 4 rem wide
box). Fixed steps inside components use the default scale: 4, 8, 12, 16, 24, 32, 48, 64 px
(`1, 2, 3, 4, 6, 8, 12, 16`).

## Radius

| Token | Value | Use |
|---|---|---|
| (none) | 0 | Photos, bands, panels, tables, the film, machine cards' image |
| `rounded-xs` | 2 px | Buttons, inputs, selects, checkboxes, thumbnails |
| `rounded-sm` | 4 px | Dropdown panels, toasts, admin cards |
| `rounded-md` | 8 px | Stacked cards (home catalogue, service process), dialogs |
| `rounded-full` | pill / circle | Tags (application, material), icon buttons, the language switch |

Nothing else. `rounded-lg`, `rounded-xl`, `rounded-2xl` do not exist on the public site.

## Shadow and blur

| Token | Value | Use |
|---|---|---|
| `shadow-island` | `0 8px 24px -12px rgb(0 25 65 / 0.35)` | Dropdowns, the floating quote bar |
| `shadow-stack` | `0 24px 48px -24px rgb(0 15 41 / 0.55)` | Stacked cards, dialogs |

No shadow on machine cards, buttons or images. No glow, no coloured shadow.

## Breakpoints

Tailwind defaults: `sm` 640, `md` 768, `lg` 1024, `xl` 1280, `2xl` 1536. The header shows the
inline navigation from `xl`. Content is checked at 360, 390, 768, 1024, 1280, 1440 and 1920.
